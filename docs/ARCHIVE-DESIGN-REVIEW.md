# アーカイブの当時のデザインを復元

2026-10-20。公開中のCSSを作り直すのではなく、Gitに残るv1のスタイルと照合して復元しました。現時点はローカル変更で、push・デプロイ・有料API呼び出しは行っていません。

## 原因

`assets/index-dibtv9up.css` の先頭に、途中で切れた外部フォントURLが残っていました。URL内のセミコロンまでを削ったため、その後の文字列が不正なCSSとして残った状態です。HTTP200でもスタイルは適用されず、v1はブラウザ標準の文字・ボタンで表示されていました。

`8b5ea54` の元のCSSと照合し、外部フォントの`@import`全体だけを除いた元の本文へ戻しました。配色・紙面・余白・タイポグラフィ指定・ナビ・ボタンを新しいデザインに置き換えていません。外部フォントへは接続せず、端末のフォントで表示します。

## 変更

- `assets/index-dibtv9up.css`：元のスタイル本文を復元。
- `original.html`：表示専用の案内とキャッシュ更新用URL。
- `src/original.js`：旧入力欄は隠さず、当時の形を残して無効化・表示専用に。メモリ内の保存代替は維持。
- `src/archive-previews/*.jpg`：保存版そのものを撮影したプレビュー。新しい見た目のモックではありません。
- `src/desk-app.js`：アーカイブに実画面プレビューを置き、押すと保存版をそのまま開く構成へ。研究の説明は折りたたみに移動。
- `src/phase2-feature.css`：プレビュー画像・リンクのレイアウト。
- `index.html`：更新した画面とスタイルのキャッシュ更新用URL。
- `scripts/dev-server.mjs`：画像の正しいContent-Type。
- `tests/archive-design-browser.py`：実際の色・見出し・画像・遷移・表示専用欄を確認。
- `tests/browser.py`：入力欄が非表示という前提を、表示されているが入力不能という仕様へ更新。
