# RE:Path Finder 参考サイトの設計ガイド

RE:Path Finderの入口、道の説明、比較、現在地の表示を改善するときに使う参考資料です。複数サイトから使い方を学び、学校の掲示板・紙・深緑という既存の見た目へ合わせます。道の具体的な中身と、次にできる操作が分かることを優先します。

開発用の参考サイトと、生徒が進路を調べるための参照先は分けます。このガイドに載る海外サービスや設計資料を、日本の入学条件・募集・費用の根拠として扱いません。生徒向けの参照先には、そのサイトで確かめられることと、確認範囲を表示します。

## UIを変更する前に確認すること

1. 改善する場面を一つ選ぶ。初めて始める、道の中身を読む、同じ関心から別の道へ進む、比較する、続きを持ち帰る、などの場面を具体化する。
2. 下の参考元から、同じ場面を扱うページを開く。見出し・余白・配置・部品の使い方と、説明・操作の順序を確かめる。参考元のロゴや固有イラストは流用しない。
3. 「参考元の仕組み」「Finderのどこへ適用するか」「持ち込まないもの」を変更内容へ記録する。
4. 初めて使う高校生の操作を実ブラウザで通す。部品が存在することだけでなく、押した結果と次の操作が見えるかを確認する。
5. 学校の資料らしい見た目、本人の編集、未確認事項、AI送信前の同意、保存形式を維持する。

既存の情報設計・配色・アクセシビリティ方針は [DESIGN.md](../DESIGN.md)、Treeと文章の連動は [統合UXの記録](INTEGRATED-EXPLORATION-REVIEW.md) を参照します。

## Finderへ適用する優先順位

最初に、選んだ道の内容をその場で読めるようにします。地図で枝を押した直後に、見出しと説明が見えることを確認します。次に、道の詳細からAIへ戻るときも、本人が確認したルート情報を送信前の確認へ引き継げるようにします。

入口は「少し話して考える」「まず道を眺める」を基本とし、例から入る人も同じ探索へつなぎます。候補を読む、残す、必要なら比較する、という順序を案内し、一つに決めずに終えられるようにします。

比較文は同じ確認事項の繰り返しで埋めず、学ぶ作業、日常、準備、場所、他の学び方との接点を具体化します。制度・費用・募集条件を確認していない場合は数値や対象校を補わず、本人が確かめる項目へ分けます。

### 画面で確かめる操作

- 職業名や学部名を入力しなくても探索を始められる。
- 枝を押すと、選んだ道の見出し・短い説明・次の操作が読める。
- 同じ疑問を別の方法で追う道へ、つながる理由を読んで進める。
- 外部サイトを開く前に、何を確かめられるサイトか分かる。
- 外部サイトから戻っても、候補・比較・本人メモが残る。
- 比較・進路決定・Tree編集をせずに保存して終えられる。

## 生徒向け参照先の扱い

参考サイトのリンクは、制度の存在・最新募集・本人の参加資格を一括して確認した証拠にはしません。編集サイトは学問や仕事を知る入口、官公庁や教育機関の資料は制度や条件を確かめる入口として役割を表示します。外部ページを実際に読んだのか、これから調べたいだけなのかも分けます。

外部サイトは本人の操作で別タブへ開き、相談文や本人メモをURLへ付けません。AIがページを取得していない場合は、複数サイトを読んで回答したように表示しません。参照先の変更・追加では、URL、発行元、対象範囲、確かめられること、確認日を見直します。
