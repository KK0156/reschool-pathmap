# RE:School Path Map — 試作品3号

CoD出願に向けた個人のResearch / Design Prototype。学部名や偏差値の前に、まだ見えていない道、誰かの経験から残る問い、学校を通した安全な対話を考えるための進路ノートです。実際の生徒による検証はまだ行っていません。

## 起動・検証

```sh
npm start
# http://localhost:8000
npm test
```

ビルド・依存ライブラリ・外部APIは不要。Node.jsはデータテストに、Pythonはローカル配信に使用します。ブラウザ検証はPython Playwrightと `/usr/bin/chromium` がある環境で、サーバー起動後に `python tests/browser.py` を実行してください。NetlifyのCSPを適用した検証も含みます。

## 六つのページ

- `#/`：はじめの手紙。v1から発展した研究の入口
- `#/finder`：RE:Path Finder / 面談前のメモ。三つの問いを一つずつ読み、手がかりをひらく。選択せず道のカードへ進むことも可能
- `#/paths`：道のカード。六つの記録を関心で絞り込み、三件まで並べて読む
- `#/cases`：誰かの道の記録。転機や迷いを読む六通の架空の手紙。目次から一通ずつ切り替えて読む
- `#/dashboard`：学校で見る地図。架空のクラスの固定集計と対話の手順
- `#/research`：研究のノート。問い・仮説・仕組み・限界・評価計画・v1からの発展

詳細は `#/paths/technology` 等。ハッシュルーティングで再読み込みも可能です。

## 手がかりのひらき方

`src/data.js` の道・卒業生・経歴・発言・学校の数値はすべて架空。選んだ関心との一致各2点、取り組み方・大切にしたいことの一致各1点で、重なりのある記録を三件まで表示します。同点はカード番号順。表示順は生徒の評価ではなく、合格可能性・適性・将来性を判断しません。六つの道で進路全体を網羅するものではありません。

## 安心して考えるための約束

Path Mapには名前・学校名・連絡先・成績・自由記述の入力欄がありません。選択は実行中のメモリだけにあり、再読み込みで消えます。Cookie・localStorage・sessionStorage・解析・API通信・送信フォームは使いません。学校の集計は利用者の回答を収集したものではありません。外部フォントも読み込みません。

相談ボタンは先生と話す問いと印刷用メモをひらく機能です。予約・送信・直接連絡は行いません。将来の対話は先生の内容確認、学校の承認、保護者への説明と必要な同意、学校管理の場を通す設計案です。本人確認や承認を実行する仕組みはありません。

公開先によるアクセスログはホスティング側の管理範囲です。

## 元のRE:School v1

`/original.html` から「卒業の、その続きを。」へ戻れます。ナビゲーション・フッター・研究ノートに入口があり、旧画面にはPath Mapへ戻るリンクがあります。

v1の既存バンドルを使用しますが、次の互換・安全対応を施しています。

- `/original.html?view=…` 内で旧画面を移動し、再読み込み・ブラウザの戻る操作でも旧試作品を表示
- `src/original.js` が既存の保存呼び出しを閲覧中だけのメモリオブジェクトへ置き換え、ブラウザの保存領域を読み書きしない
- 自由記述・個人情報になり得る入力欄を無効化して非表示にする
- 旧文面の保存・送信に関する説明を閲覧用に調整
- 旧CSSのGoogle Fonts読み込みを除去

元の活動フローや見た目の記録を読むための入口です。自由記述が必要だった旧フローの回答完了を再現する用途ではありません。v1から試作品3号へ戻ると、一時的な選択は引き継ぎません。

## Netlify

GitHubリポジトリの `main` を接続します。

- Build command：空欄
- Publish directory：`.`
- `netlify.toml`：配信先とCSP等のセキュリティヘッダー
- `_redirects`：既存の静的サイト用フォールバック
- Functions・環境変数・DB・Netlify Forms：不要

実ファイルである `/original.html` はフォールバックより優先して配信されます。

## デザインと検証

デザイン判断・参考にした考え方は `DESIGN.md` に記録しています。紙色・紺・明朝体・罫線を基本とし、影・グラデーション・強いCTAは使いません。

キーボード操作、フォーカス、スマートフォン、色以外の選択状態、本文スキップ、noscript、フォームエラー、aria-current、aria-pressed、role=statusを維持しています。ブラウザ検証は探索・比較・絞り込み・v1往復・再読み込み・保存されないこと・NetlifyのCSPを確認します。アクセシビリティの正式な適合認証を示すものではありません。
