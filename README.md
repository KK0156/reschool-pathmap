# RE:School Path Map — 試作品3号

学部名の前に「どんな道があるか」を探索するResearch Prototype。v1の紙色・紺色・明朝体・手紙の構成を引き継いだ、ビルド不要の静的サイトです。外部フォントを読み込まず、端末の日本語フォントを使用します。

## 起動・検証

```sh
npm start
# http://localhost:8000
npm test
```

ブラウザ動作検証は、Python PlaywrightとChromiumのある環境で、ローカルサーバー起動後に `python tests/browser.py` を実行します（Chromiumは `/usr/bin/chromium`）。

Node.jsはテスト用です。配信にはHTML/CSS/JSを配信できるサーバーのみが必要です。ファイルを直接開くのではなくHTTPで起動してください。

## 6画面

- `#/`: Top / Concept
- `#/finder`: RE:Path Finder。関心・取り組み方・価値観から最大3件の候補と一致理由を表示
- `#/paths`: Path Cards。関心による絞り込み、最大3件の比較、詳細と最初の一歩
- `#/cases`: Alumni / Case Database。6件の架空事例、関心による絞り込み
- `#/dashboard`: School Dashboard。固定の架空集計と学校を通す接続手順
- `#/research`: Research Explanation。仮説、候補の計算方法、限界、評価計画、データ方針

カードの詳細は `#/paths/technology` 等。ハッシュルーティングのため、詳細URLの再読み込みも静的配信で動作します。

## データと安全設計

`src/data.js` の道・人物・経歴・発言・集計値はすべて架空です。Finderはタグの一致を計算し、関心の一致各2点、取り組み方・価値観各1点で最大3件を表示します。同点はカード番号順。適性、合格、将来性の診断や推薦ではありません。

名前・学校名・連絡先・成績・自由記述の入力欄はありません。選択はメモリ上だけで保持し、再読み込みで消えます。Cookie、ブラウザストレージ、解析、API通信、送信フォームはありません。Dashboardは操作結果を集計しません。公開先によるアクセスログの扱いはホスティング側の設定を確認してください。

相談ボタンは先生と話すための問いと印刷機能を表示するだけです。メール送信・予約・直接連絡は行いません。将来の外部接続には先生の内容確認、学校の承認、保護者への説明と必要な同意、学校管理の対話の場を想定しています。この試作品に本人確認や実際の承認システムはありません。

## Netlifyで公開

GitHubリポジトリをNetlifyに接続し、この変更を含むブランチを選択します。

- Build command: 空欄（ビルド不要）
- Publish directory: `.`
- `netlify.toml` に配信先とセキュリティヘッダーを定義
- `_redirects` の既存SPAフォールバックを維持
- Functions、環境変数、データベース、Netlify Formsは不要

Netlifyへのデプロイ自体はこの変更に含みません。

## ファイル構成・v1からの変更

- `index.html`: 試作品3号のタイトル・説明、新しい編集可能ソースの読み込み、本文スキップリンク
- `src/app.js`: 6画面、探索、絞り込み、比較、詳細、先生への相談準備
- `src/data.js`: 6つの道、6件の架空卒業生事例、学校のサンプル集計、タグ一致ロジック
- `src/styles.css`: v1の世界観を継承したレイアウト、モバイル対応、キーボードフォーカス、印刷表示
- `netlify.toml`: ビルド不要の配信設定、外部通信・フォーム送信を禁止するCSP等
- `package.json`: ローカル起動・テストコマンド（依存ライブラリなし）
- `tests/data.test.js`: データ参照整合性と全選択肢の探索結果を検証
- `tests/browser.py`: 6画面・探索・比較上限・絞り込み・保存なし・モバイル表示をブラウザで検証
- `README.md`: 起動、画面、データ方針、限界、Netlify公開手順

v1の `assets/` 内の配信済みバンドルと既存SVGは履歴・参考用に残し、新しいサイトから旧バンドルは読み込みません。
